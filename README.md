# ✨ FinFlow — твой личный поток финансов

**FinFlow** — это будущий сервис для тех, кто хочет перестать задаваться вопросом:  
*«Куда снова ушли все деньги?»*

Проект помогает собрать личные финансы в одном месте: отслеживать доходы и расходы, управлять счетами, видеть общий баланс и замечать собственные финансовые привычки.

## 💡 Возможности

- создание и управление финансовыми счетами;
- добавление доходов и расходов;
- просмотр баланса каждого счёта;
- история финансовых операций;
- краткая финансовая сводка;
- экспорт данных для анализа и хранения.

## 🌱 Идея проекта

FinFlow задуман как простой и понятный финансовый помощник на каждый день.  
Без сложных таблиц и лишних действий — только самое важное: деньги, операции и ясная картина личного бюджета.

Сейчас проект реализуется как консольное приложение. В дальнейшем FinFlow может развиться в полноценный сервис с личным кабинетом, категориями расходов, финансовыми целями, графиками, лимитами бюджета и синхронизацией между устройствами.

## 🛠 Техническая часть

Проект разработан на **TypeScript** и запускается в среде **Node.js**.

Для взаимодействия с пользователем используется консольный интерфейс и библиотека **Inquirer**: она позволяет создавать удобные меню, выбирать действия и вводить данные пошагово.

Основные данные приложения — счета и транзакции. Для каждой операции сохраняются тип, сумма, дата, описание и связь с выбранным счётом. Также предусмотрен экспорт списка транзакций в формат **CSV**, чтобы данные можно было открыть в Excel или Google Sheets.

## 🎯 Цель

Помочь пользователю выстроить более осознанные отношения с деньгами: понимать свои траты, планировать будущее и увереннее управлять личным бюджетом.
