# ✨ FinFlow — твой личный поток финансов

**FinFlow** — консольный финансовый помощник для тех, кто хочет перестать
задаваться вопросом: *«Куда снова ушли все деньги?»*

Приложение собирает личные финансы в одном месте: счета, доходы и расходы,
конверты с месячными лимитами, дневной лимит трат и мягкая геймификация за
финансовые привычки.

## 💡 Возможности

- создание и управление счетами с уникальными ID;
- добавление доходов и расходов с категорией, датой и комментарием;
- удаление операций и счетов с подтверждением (удаление счёта каскадное);
- баланс по каждому счёту и общий итог по всем счетам;
- **конверты**: месячный лимит на каждую из 7 категорий, полоса расхода и
  остаток, предупреждение при перерасходе;
- **safe-to-spend**: сколько можно тратить в день, чтобы дожить до конца месяца;
- спарклайн расходов за последние 14 дней;
- **геймификация**: XP, уровни и 8 достижений за привычки, а не за суммы;
- экспорт операций в CSV (открывается в Excel и Google Sheets);
- сохранение состояния в JSON с защитой от повреждённого файла.

## 🌱 Идея проекта

FinFlow задуман как простой и понятный помощник на каждый день: без сложных
таблиц и лишних действий — только деньги, операции и ясная картина бюджета.

Идея в том, что осознанность рождается из привычки записывать и видеть предел.
Поэтому в приложении есть лимиты по конвертам и дневной ориентир трат: они
превращают «сколько я потратил» в «сколько мне ещё можно».

## 🛠 Техническая часть

Проект написан на **TypeScript** и запускается в **Node.js**. Интерфейс —
консольный, ввод через **Inquirer**; для вывода используется **chalk** и
**cli-table3**.

Данные — счета и операции. Для каждой операции хранятся тип, сумма в копейках,
категория, дата в формате ISO и комментарий. Состояние сохраняется в
`data/state.json`; экспорт — в CSV.

### Технические решения

| Решение | Почему так |
|---|---|
| Деньги в копейках (`number`) | `0.1 + 0.2 !== 0.3`; целые копейки исключают накопление ошибки |
| Баланс вычисляется, а не хранится | вычисляемый не может «разойтись» с суммой операций |
| Даты — строки ISO `YYYY-MM-DD` | сортировка лексикографическая, нет сдвигов часового пояса |
| Арифметика дат через номер дня от эпохи | не зависит от перехода на летнее время |
| Валидация в конструкторах моделей | некорректную операцию невозможно создать в принципе |
| `strict` + `noUncheckedIndexedAccess` + `noUnusedLocals` | обращение по индексу даёт `T \| undefined`, мёртвый импорт не собирается |
| `inquirer.prompt` только в `ui/prompts.ts` | один канал ввода — одна точка изменения |
| `JSON.parse` только в `services/stateCodec.ts` | разбор недоверенных данных изолирован и проверяется по полям |
| XP — функция от данных, а не счётчик | прогресс нельзя «накрутить» повторными запусками |
| Повреждённый файл → `.broken` | пользователь не теряет данные молча |
